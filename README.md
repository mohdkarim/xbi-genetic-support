# Genetic Alpha

Do biotech companies with genetically-supported drug pipelines outperform those without?

This analysis uses [Open Targets](https://platform.opentargets.org/) genetic association scores (Feb 2020 release) to classify 126 [XBI ETF](https://www.ssga.com/us/en/intermediary/etfs/funds/spdr-sp-biotech-etf-xbi) holdings as genetically-supported (GS) or non-GS, then compares equal-weight portfolio returns from January 2, 2020 to April 1, 2026.

**[View the interactive results](https://mohdkarim.github.io/xbi-genetic-support/)**

## Why

Published evidence suggests that drug programs with human genetic support are more likely to succeed in clinical trials ([King et al., Nature 2024](https://doi.org/10.1038/s41586-024-07316-0); [Nelson et al., Nature Genetics 2015](https://doi.org/10.1038/ng.3314)). This analysis tests whether that translational advantage shows up in stock returns — whether investors are compensated for backing genetically-validated science.

## What we found

- **16 GS companies** (lead program genetic association score > 0.80) returned **+102.0%** on average
- **110 non-GS companies** returned **+40.0%** on average
- **Alpha: +61.9 percentage points**, beating 90.6% of 10,000 random portfolio draws of the same size
- Among the 22 companies that could actually be scored (16 GS vs 6 non-GS), alpha was **+88.7pp** (95.7th percentile, all combinations exhaustively enumerated)
- The signal holds after controlling for pipeline phase: among Phase 3+ companies, GS returned +85.9% vs non-GS at -17.0%

## How to reproduce

### Prerequisites

- Python 3.9+
- ~800 MB disk space for the Open Targets data file

### Setup

```bash
git clone https://github.com/mohdkarim/xbi-genetic-support.git
cd xbi-genetic-support
pip install -r requirements.txt
```

Download the Open Targets 20.02 genetic association data (~766 MB compressed):

```bash
wget -P opentargets/ \
  https://ftp.ebi.ac.uk/pub/databases/opentargets/platform/20.02/output/20.02_association_data.json.gz
```

### Run the pipeline

Scripts run sequentially — each one's output feeds the next:

```bash
python3 scripts/03_score_ot.py            # Score pipeline against OT 20.02 (~5 min)
python3 scripts/04_fetch_returns.py       # Fetch stock returns via Yahoo Finance (~5 min)
python3 scripts/05_build_master.py        # Build one-row-per-company master file
python3 scripts/06_analyze.py             # Portfolio analysis, Monte Carlo, robustness checks
python3 scripts/08_quarterly_returns.py   # Quarterly return breakdown
python3 scripts/09_prepare_webapp_data.py # Generate webapp data (docs/js/data.js)
```

After running, open `docs/index.html` to see the results locally.

## Methodology notes

- **Scoring**: Only the Open Targets 20.02 NDJSON release (Feb 2020) is used for genetic association scores — no current API lookups, eliminating look-ahead bias by construction
- **Threshold**: A company is GS if its lead program's `genetic_association` score > 0.80
- **Lead program**: The most advanced clinical trial with a scoreable drug-gene-disease mapping. Combination partners and standard-of-care comparators are excluded via a blocklist of ~80 drugs
- **Returns**: Jan 2, 2020 to Apr 1, 2026. Active tickers via Yahoo Finance; delisted tickers from SEC 8-K filings
- **Benchmark**: 10,000 random draws of 16 companies from the 126-company universe (seed = 42)
